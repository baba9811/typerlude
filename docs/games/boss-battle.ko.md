# 보스전

<p align="center"><a href="boss-battle.md">English</a> · <strong>한국어</strong></p>

보스전은 **게임 → 보스전**에서 시작하는 한국어·영어 타자 전투입니다. 모든 보스가 기본 전투
규칙을 공유하지만, 입력 패턴과 압박 방식, 2페이즈 행동은 서로 다릅니다.

## 전투 규칙

- 하트 3개를 지키면서 활성 전투 시간 90초 안에 보스를 쓰러뜨리세요.
- 체력이 절반이 되면 2페이즈가 시작됩니다. 스킬·전환 연출 중에는 입력이 잠기고 활성 타이머가
  멈춥니다.
- `Esc`로 일시 정지합니다. 정지 중 `q` 또는 `ㅂ`을 두 번 누르면 나갑니다.
- 결과 화면에서는 `r` 또는 `ㄱ`으로 같은 전투를 다시 시작하고, `Enter` 또는 `Esc`로 해당
  보스의 옵션에 돌아갑니다.
- 붙여넣기는 무시됩니다. 일반 입력은 `Backspace`로 고칠 수 있지만, 일부 보스는 잘못 누른 키를
  즉시 처벌합니다.

## 진행도

난이도는 보스별로 따로 열립니다. 클리어한 난이도에 따라 해당 보스의 별도 채워집니다.

| 클리어 | 별 | 새로 열리는 항목 |
| --- | --- | --- |
| 없음 | ☆ ☆ ☆ ✧ | IRON WARDEN 쉬움 |
| 쉬움 | ★ ☆ ☆ ✧ | 같은 보스의 보통과 다음 보스의 쉬움 |
| 보통 | ★ ★ ☆ ✧ | 같은 보스의 어려움 |
| 어려움 | ★ ★ ★ ✧ | 같은 보스의 Hell |
| Hell | ★ ★ ★ ✦ | 해당 보스 최종 클리어 |

별과 난이도 해금은 한국어·영어가 공유합니다. 개인 최고 점수는 보스·언어·난이도별로 따로
저장합니다.

## Hell 난이도

Hell은 어려움 단어 풀을 사용하면서 체력과 패턴 타이밍을 더 빡빡하게 조정합니다. 이중선
`╬ HELL ╬ // REDLINE` 프레임으로 색상이 없는 터미널에서도 구분되며, 터미널 깜빡임 효과는
사용하지 않습니다. 한국어·영어 모두 540 KPM·정확도 98.5%인 플레이어가 75~88초에 모든
보스를 클리어하는 것을 목표로 맞췄습니다. 420 KPM·정확도 97%인 플레이어는 막바지까지
도달하지만 클리어하지 못하도록 설계했습니다.

## 보스 목록

### 1. IRON WARDEN

- **패턴:** 프롬프트 3개를 완성해 장갑 잠금을 부수세요. 코어가 노출된 동안 입력한 프롬프트는
  두 배의 피해를 줍니다.
- **실패:** PILE DRIVER가 완성되면 하트 1개를 잃고 장갑 잠금이 모두 초기화됩니다.
- **2페이즈:** 장갑과 코어의 입력 시간이 짧아집니다.
- **대표 스킬:** PILE DRIVER와 코어 노출 타격 구간.

### 2. THORN QUEEN

- **패턴:** 덩굴 2개가 동시에 자랍니다. 첫 물리 키로 일치하는 덩굴 하나를 선택하고, 꽃이 피기
  전에 입력을 끝내세요.
- **실패:** 꽃이 핀 덩굴 하나당 하트 1개를 잃고 해당 덩굴이 교체됩니다.
- **2페이즈:** 세 번째 덩굴이 추가됩니다.
- **대표 스킬:** THORN BLOOM과 동시 표적 선택.

### 3. NULL ARCHON

- **패턴:** 체크섬 슬롯 3개를 채워 공허의 성가를 역전시키고 추가 피해를 주세요.
- **실패:** 키를 잘못 누르면 현재 입력이 지워지고 저장한 체크섬 1개가 사라집니다. 성가가 완성되면
  하트 1개를 잃습니다.
- **2페이즈:** 전환 중 C MAX가 시스템을 잠그며, 이후 성가가 빨라집니다.
- **대표 스킬:** C MAX, 체크섬 롤백, 체크섬 3개 역전.

### 4. PRISM SERAPH

- **패턴:** 거울날개 6개가 중앙 렌즈로 모입니다. 모든 자세에서 입력과 `Backspace`를 계속 쓸 수
  있지만, 렌즈가 닫힌 동안 단어를 완성하면 그 공격이 되돌아옵니다.
- **실패:** 되돌아온 공격 하나마다 보스 체력은 줄지 않고 하트 1개를 잃으며 콤보가 초기화됩니다.
  반사 중 단어를 입력하다가 마지막 글자를 렌즈가 갈라질 때까지 기다리는 것은 의도한 플레이이며,
  해제 첫 프레임부터 안전합니다.
- **2페이즈:** 날개가 열린 구간만 짧아지고, 예고와 닫힌 렌즈의 규칙은 그대로 유지됩니다.
- **대표 스킬:** 안쪽으로 모이는 거울날개, 이중선 렌즈, 플레이어 쪽으로 돌아오는 광선.

## 점수와 로컬 데이터

점수는 승리 보너스 10,000점, 남은 시간의 정수 초 × 100, 남은 하트 × 1,000, 정확도의
베이시스 포인트(100% = 10,000), 최대 콤보 × 10을 더해 계산합니다. 패배 점수도 결과 화면에는
표시하지만, 승리했을 때만 별과 개인 최고 점수를 갱신합니다.

보스전 결과는 연습 세션 기록에 추가하지 않습니다. 클리어 별과 개인 최고 점수는 로컬 설정
파일에 저장하며, 위치는 `typerlude paths`로 확인할 수 있습니다.
